# yamamars.official

ユーザーを引き込む美しいアニメーションを搭載した、モダンなWebフロントエンドテンプレートです。

##  概要
このプロジェクトは、CSSアニメーション、レスポンシブデザイン、およびインタラクティブなUIコンポーネントを組み合わせたシングルページアプリケーションです。ページを開いた瞬間からユーザーに驚きを与えるストーリー性のある演出が特徴です。

##  主な機能・特徴
- **動くグラデーション背景**: CSSだけで実装された、ゆっくり変化する幻想的な背景
- **3方向スライスアニメーション**: タイトル文字が3つに分割され、左右上から中央へ集まる演出
- **遅延フェードインボタン**: メインコンテンツの完成後に、時間差で下から現れるボタン
- **高機能ハンバーガーメニュー**: 背景オーバーレイ付きのスライドインメニュー
- **完全レスポンシブ対応**: PC、タブレット、スマホのすべてのデバイスで最適化されたレイアウト

##  使用技術 (Tech Stack)
- HTML5
- CSS3 (Flexbox, @keyframes, Custom Properties)
- JavaScript (Vanilla JS)
